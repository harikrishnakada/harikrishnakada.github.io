- Collaborated with Business Analysts to translate customer requirements into product backlog items
- Built robust APIs, asynchronous functions, and background web jobs for CRUD operations
- Developed front-end modules using Angular 8+ and TypeScript
- Created and integrated data visualization reports using Power BI service
